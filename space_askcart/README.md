AskCart: an agentic extractor + evidence explorer for e-commerce search UX. 94,643 public reviews from 5 sources (Play Store, App Store, Reddit, Amazon product reviews, Trustpilot) cut to 4 root causes by a 6-stage SQL pipeline with Bayesian app ratings and LLM-verified labels. Includes the LLM-planned agent decision audit (Gemini), demand/seasonality signals, and a live mini-extraction probe.

All analysis runs in your browser from bundled artifacts. The extractor's LLM is Gemini via the owner's Gemini API; no Gemini or other vendor model is used. Companion MVP (guided shopping search, 25K SKUs): separate Vercel deploy. Do not paste personal information into the probe fields.
